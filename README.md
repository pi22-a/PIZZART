# PIZZART

**해보기 → [pizzagame.app](https://pizzagame.app)** · 설치 없이 브라우저에서 바로. 3~9명 필요.

3~9명이 즐기는 웹 추리 게임.

> TypeScript · Node.js(WebSocket) · Vite · Canvas · Vitest — 프레임워크 없이 만들었다.
> 규칙은 네트워크를 모르는 순수 함수에 있고, 서버가 유일한 심판이다.

한 명이 제시어를 보고 **원형 캔버스**에 그림을 그린다. 그 그림은 **피자처럼 부채꼴로 잘려**
나머지에게 한 조각씩 흩어진다. 모든 조각은 **둥근 쪽이 위로 오게 회전되어** 있어서
자기 조각이 원본의 어느 방향이었는지 아무도 모른다.

자기 조각 하나만 보고 **먼저 알아맞히면 점수를 가져간다.** 빨리 맞힐수록 높은 점수다.

10점에서 시작해 **회차가 넘어갈 때마다 1점씩 깎인다.** 회차가 넘어가면 조각이 한 장씩
자동으로 늘어나므로, 깎이는 1점은 조각 한 장을 더 보는 값이다. 틀린 제출도 1점이다.

아직 못 맞힌 사람이 **전부 라운드 스킵을 누르면** 남은 시간을 건너뛰고 바로 다음 회차로
간다. 스킵을 누른 사람은 그 회차에 답을 낼 수 없다 — 실수로 점수를 잃지 않게 막아둔 것이다.

**출제자의 점수는 마지막 조립판에서만 나온다.** 조각을 제자리에 끼워 보여줬을 때
한 명이라도 맞히면 5점이고, 여러 명이 맞혀도 5점이다. 반대로 조각만 보고 다들 일찍
맞혀버리면 라운드가 조립판에 닿지 않아 0점이다 — **조각으로는 못 알아보지만 합치면
알아보는** 그림이 출제자에게 가장 좋은 그림이다.

출제자가 그리는 동안 기다리는 사람들은 **같이 낙서판**에 마음대로 그릴 수 있다.
낙서는 점수와도 제시어와도 아무 상관이 없고, 정답을 아는 쪽(출제자·관전자)에게는 보이지 않는다.

## 이야기

**결과 화면과 최종 화면에서만** 한마디씩 나눌 수 있다. 정답이 공개된 뒤라 새어 나갈 것이 없는
자리다. 회차 중에는 서버가 아예 받지 않는다 — 그 자리에는 정답을 아는 사람이 셋 있고
(출제자·관전자·먼저 맞힌 사람), 그중 하나가 한 줄만 흘려도 나머지가 공짜로 점수를 가져간다.

로그는 **한 판 내내 이어진다.** 라운드가 바뀌는 자리에 구분선이 들어가므로,
최종 화면에서 그 판 전체의 반응이 한눈에 되짚어진다. 한 판 더를 누르면 점수와 함께 비워진다.

이름 색은 낙서판에서 쓰던 그 색이다.

## 관전

**관전**을 고르면 그리지도 맞히지도 않고 출제자와 같은 것을 본다 — 제시어, 그려지는 원본,
남들이 무슨 조각을 들고 헤매는지까지. 인원에도 출제 순번에도 들어가지 않는다.

**로비에서만 고를 수 있다.** 그래서 게임 도중에 들어온 사람은 자동으로 관전자가 되고,
**모든 사람이 한 번씩 출제를 마쳐 판이 끝날 때까지** 관전으로 남는다. 로비로 돌아오면 그때 참여로 바꾼다.

관전자는 정답을 아는 사람이라 참가자 목록에 👁로 표시된다 — 통화 중에 흘릴 수 있는 사람이
누구인지 나머지가 알아야 하기 때문이다.

## 제시어

주제 **9개**, 단어 **450개** — 동물 · 음식 · 전자제품 · 직업 · 도구 · 자연 · 탈것 ·
건물 · 이야기 속 존재. 주제마다 정확히 50개다.

늘리려면 `content/words/`에 JSON을 하나 더 넣는다.

```json
{ "topic": "악기", "words": ["기타", "피아노"] }
```

파일 이름 앞의 번호가 **화면에 뜨는 주제 버튼의 순서**다. 번호가 없으면 파일 이름의
알파벳순이 되어 한글로 보면 뒤죽박죽이 된다.

**같은 단어를 두 주제에 넣지 않는다.** 넣으면 그 단어의 주제가 뽑을 때마다 달라지는데,
맞히는 사람에게 주제는 힌트이므로 같은 그림에 다른 힌트가 붙는 셈이 된다.
`npm test`가 이것과 주제당 개수를 확인한다.
