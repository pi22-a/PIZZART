# TAKBON

3~5명이 각자 **고대 문양의 서로 다른 조각**만 본 채, 하나의 석판에 **동시에 그려**
원본을 복원하는 웹 협동 게임.

핵심 장치는 하나다. 조각 창이 자기 구역에서 **반 칸 밀려 있어서**, 내 구역의 절반을
내가 볼 수 없다. 그 절반은 왼쪽 이웃이 보고 있다. 그래서 **말로 물어봐야만** 그릴 수 있다.

음성은 게임 안에 없다. 디스코드·카톡 통화를 켜놓고 하는 것을 전제로 만들었다.

---

## 실행

```bash
npm install     # 처음 한 번만
npm run dev
```

명령 하나로 두 프로그램이 함께 뜬다 — 게임 서버(8080)와 페이지 서버(5173).
로그 앞에 `[서버]` `[화면]` 이 붙어 어느 쪽 출력인지 구분된다.
**끄려면 `Ctrl + C` 한 번.** 둘 다 같이 정리된다.

브라우저에서 열기:

```
http://localhost:5173/?room=아무거나
```

같은 방 코드를 쓰는 사람끼리 만난다. **3명 이상**이어야 시작할 수 있다.
`?name=이름` 을 붙이면 이름을 묻지 않는다.

### 인원이 모자랄 때

가짜 플레이어를 붙일 수 있다.

```bash
node scripts/fake-player.mjs 방코드 봇1 --draw --ready
```

`--draw` 는 구간마다 자기 구역에 물결선을 긋고, `--ready` 는 완성을 누른다.
끝내려면 `Ctrl + C`.

### 다른 네트워크에 있는 사람과 하기

브라우저가 보기엔 포트가 5173 하나뿐이므로 터널도 하나만 뚫으면 된다.

```bash
brew install cloudflared   # 처음 한 번만
npm run tunnel             # 새 터미널 탭에서
```

`npm run dev` 는 계속 떠 있어야 하므로 터널은 **다른 탭**에서 띄운다.
발급된 https 주소 뒤에 방 코드를 붙여 나눠주면 된다:

```
https://랜덤-단어들.trycloudflare.com/?room=1
```

페이지가 https면 웹소켓도 자동으로 wss가 되므로 따로 만질 것이 없다.
**터널 주소는 켤 때마다 바뀐다.**

터널 도메인은 `vite.config.ts` 의 `allowedHosts` 에 미리 열어두었다 —
vite는 모르는 호스트 이름으로 온 요청을 막기 때문이다(DNS 리바인딩 방어).
다른 서비스를 쓴다면 `TAKBON_HOST=주소 npm run dev` 로 넘긴다.

## 알아둘 것

**개발 중이 아니면 `npm run dev:watch` 를 쓰지 말 것.** 파일이 하나라도 바뀌면 서버가
재시작되면서 **진행 중인 방이 전부 날아간다.** 방 상태는 메모리에만 있다.

**서버는 인스턴스 하나여야 한다.** 여러 개로 늘리면 같은 방 코드인데 서로 다른 서버에
붙어 방이 갈린다.

## 명령 목록

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 게임 서버 + 페이지 서버 (플레이용) |
| `npm run dev:watch` | 위와 같되 서버가 파일 변경 시 재시작 (개발용) |
| `npm run tunnel` | 외부에서 접속할 수 있는 https 주소 발급 |
| `npm test` | 테스트 전체 실행 |
| `npm run test:watch` | 테스트 감시 모드 |

## 구조

```
src/shared/    타입 · 격자와 선분 교차 · 메시지 프로토콜
src/server/    조각 분할 · 채점 · 세션 상태 머신 · WebSocket
src/client/    캔버스 · 조각 뷰 · 화면 · 통신
content/       문양 JSON · 난이도 파라미터
```

핵심 로직 셋(`geometry` · `scorer` · `fragmenter`)은 네트워크도 상태도 모르는
**순수 함수**다. 나중에 Unity로 옮길 때 언어만 바뀌고 로직은 그대로 넘어간다.

**원본 문양은 채점이 끝나기 전에는 클라이언트로 내려가지 않는다.** 치팅 방지가 아니라
게임이 성립하기 위한 조건이다 — 개발자 도구로 답이 보이면 협상할 이유가 사라진다.
이 불변식은 테스트로 고정되어 있다.
